# My_Lending — Персональный лендинг frontend-разработчика

> **Живая демонстрация доступна по ссылке:** [https://nnnekita.github.io/My_Lending/](https://nnnekita.github.io/My_Lending/)

## Описание

Персональный лендинг-портфолио Никиты Игоревича — frontend-разработчика. Сайт демонстрирует навыки адаптивной вёрстки, работы с JavaScript и создания современных пользовательских интерфейсов.

Проект находится в **открытом доступе** и доступен для просмотра, изучения и использования в качестве примера.

## Технологии

- **HTML5** — семантическая разметка
- **CSS3/SCSS** — стилизация, адаптивная вёрстка
- **JavaScript (ES6+)** — интерактивные компоненты
- **Swiper** — слайдер для портфолио
- **Mobile-first** — адаптивный дизайн для всех устройств

## Разделы сайта

- **Hero** — приветственный экран с краткой информацией
- **Обо мне** — опыт, фокус и подход к работе
- **Навыки** — HTML/CSS, JavaScript, React, инструменты
- **Портфолио** — слайдер с примерами проектов
- **Контакты** — способы связи (Email, Telegram, VK)

## Особенности

- Полностью адаптивная вёрстка
- Плавные анимации и переходы
- Доступность (ARIA-атрибуты, skip-link)
- Оптимизированная загрузка изображений
- Кросс-браузерная совместимость

## Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/Nnnekita/My_Lending.git

# Перейти в директорию проекта
cd My_Lending

# Установить зависимости
npm install

# Открыть index.html в браузере
```
