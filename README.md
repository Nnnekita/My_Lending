# My_Lending — Мой персональный лендинг frontend-разработчика

> **Живая демонстрация:** [https://nnnekita.github.io/My_Lending/](https://nnnekita.github.io/My_Lending/)

## Описание

Это мой персональный лендинг-портфолио. Я создал этот сайт, чтобы продемонстрировать свои навыки адаптивной вёрстки, работы с JavaScript и создания современных пользовательских интерфейсов.

Проект находится в **открытом доступе** — вы можете просматривать его, изучать код и использовать как пример.

## Технологии

- **HTML5** — семантическая разметка
- **CSS3/SCSS** — стилизация, адаптивная вёрстка
- **JavaScript (ES6+)** — интерактивные компоненты
- **Swiper** — слайдер для портфолио
- **Mobile-first** — адаптивный дизайн для всех устройств

## Разделы сайта

- **Hero** — приветственный экран с краткой информацией обо мне
- **Обо мне** — мой опыт, фокус и подход к работе
- **Навыки** — HTML/CSS, JavaScript, React, инструменты
- **Портфолио** — слайдер с моими проектами
- **Контакты** — как со мной связаться (Email, Telegram, VK)

## Особенности

- Полностью адаптивная вёрстка
- Плавные анимации и переходы
- Доступность (ARIA-атрибуты, skip-link)
- Оптимизированная загрузка изображений
- Кросс-браузерная совместимость

## Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/Nnnekita/My_Lending.git

# Перейти в директорию проекта
cd My_Lending

# Установить зависимости
npm install

# Открыть index.html в браузере
```
