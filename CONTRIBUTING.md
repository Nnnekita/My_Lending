# Как внести свой вклад

Спасибо за интерес к проекту! Вот несколько простых правил:

## Баг-репорты

Если нашёл баг — создай [Issue](../../issues) с описанием:
- Что ожидал
- Что произошло
- Шаги для воспроизведения
- Скриншот (если есть)

## Pull Requests

1. Форкни репозиторий
2. Создай ветку (`git checkout -b feature/имя-фичи`)
3. Внеси изменения
4. Запушь ветку (`git push origin feature/имя-фичи`)
5. Создай Pull Request

## Стиль кода

- Используй 2 пробела для отступов
- Одинарные кавычки в JS
- Точка с запятой в конце строк
- BEM-нейминг для CSS-классов
